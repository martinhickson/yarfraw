1. download and install maven 2 
2. change directory to /yarfraw and type 'mvn'
3. the jar file can be found under /yarfraw/target/

Notes:
- The normal build can take up to a couple of minutes because of many
unit tests attempt to read rss feeds from remote locations. If you 
don't want to run these remote read tests but at the same time do not
want to skip all tests entirely, add '-Denv=dev' to the end of the mvn
command, this will trigger a profile call 'dev' that will exclude 
these remote read tests.

for example: 'mvn clean install -Denv=dev'

- You cannot use -X maven 2 option to build the project because
jaxb generates some debug classes that will cause collisions if 
this flag is set (because multiple schemas are merged to the same
java package). If you know how to fix this, please let me know.

- if you are building the site, the findbugs report will run the build process out of memory.
use 'export MAVEN_OPTS=-Xmx512M' to first increase the max heap size before running it.
on Windows, you need ot go to ControPanel->System and add the MAVEN_OPTS env variable.
